## What is sillyShootingGame

its is a fork of assultcube that i decided to make to mess around with the source code.

## what is different

- i decided that a lot of the guns needed cartoonish knockback, quickswap and no recoil.
- I also added sprinting, hitmarkers, selectable secondarys and a new gun
- tried to patch up the physics system

## sot tdm mode
- new mode that makes it so that you only have one bullet in each gun --> emulates sot tdms but with quickswap
